# **Control Menu**

Use the control menu to change game settings, manage the hand, and move through the session.

**Undo**: Reverts the most recent action recorded.

**Settings**: Change various visual settings.

**Compact Mode**: An action entry only screen built for smaller devices.

**GO Mode**: Switch the game to GO Mode (e.g. you don't have a deck right now)

**TV View**, **Spectator View**, and **Share**

- Use these options to display the table in different layouts or share public links.
- See Viewing Options for more detail.

**Spectator View**: Allows viewers who are not at the table to follow the hand on another device.

**Share**: Copies links for TV and spectator views.

**Hand History**: Shows all actions taken during the session.

- You can export hand history to Google Sheets for later review.

**Variant and Side Games**

- Adjust the game variant, betting structure, and side games.
- Side games are only available in cash games.

**Temp Game**

- Run a temporary game that is different from the main game.
- Choose to run it now or make it a recurring game.

**Bomb Pot**

- Run a bomb pot, with many variants available.
- Default ante is 5 BB.

**Rebuy / Cash Out**

- Cash games only.
- Enter the amount added for a rebuy.
- Cashing out removes a player from the table.

**Late Entry / Late Registration**

- Add a new player after the hand has started.
- Cash games: choose the seat to the left of the player who should sit next to the new arrival.
- Tournaments: choose the seat or the player to the left of whom the new player should sit.

**Structure Setup**: Update the tournament structure, levels, and related settings.

**Call Clock**

- Available only when the action clock is enabled.
- Calls the clock on the player with action.
- Click again to cancel.

**End Hand**: Advances to the next hand.

- Hole cards are optional, but the pot winner must still be selected.

**End Session**: Ends the session and lets you choose whether to save it for later.

## Action Tracking

Click the relevant action button (or use its corresponding keyboard shortcut) to record the action for the current player.

Available actions include:

- Fold (F)
- Check/Call (C)
- Bet/Raise (R)
- Min-bet/Min-raise (M)
- Straddle (S)
- Pot (P)
- All-In (Shift+A)

For a bet or raise, enter the amount before confirming the action.

If checking is available, the Fold button is disabled. If a player accidentally or intentionally folds when a check was available, you can still select Fold and confirm the action (or press F+F) in the follow-up prompt.

### **Out of Turn**

Use the out-of-turn action option to record an action that was taken before the current player’s turn.

The out-of-turn procedure follows standard poker rules and should be applied consistently with the table’s live action.

### **Action History**

Action History shows every action taken during the current hand.

- If amounts are hidden, the action is still shown, but the bet size and updated pot size remain hidden.
- This view is useful for reviewing the hand flow and confirming player decisions.

## **All-In**

When players are all-in and there is no more action, the display switches to list view so that the table can review the full hand state clearly.

At this stage:

- Enter each player’s hole cards
- Enter any community cards already dealt
- Review each player’s equity and win percentage
- See outs if a player is behind
- View the chance of a chop if a chop is possible

As new community cards are dealt, enter them into the tracker so that equity, outs, and chop chances update in real time.

## **Viewing Options**

Use viewing options to change how the table is displayed during play.

Table View

- The standard in-game view.
- Shows the table layout and player positions.

List View

- Displays the hand in a broadcast-style list format.
- Useful for clear review of player actions and board state.

TV View

- Designed for a screen placed near the table or in a dedicated display area.

Spectator View

- Intended for viewers not sitting at the table or at the tournament venue.
- This view shows pot size and stack values even when amounts are hidden.

Share

- Copies links to the TV and spectator views so they can be shared with others.

<Note>
  When players are all-in, all viewing modes switch to list view so everyone can see the hole cards, community cards, equity, and outs for each player.
</Note>
