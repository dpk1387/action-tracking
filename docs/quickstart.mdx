## Cash Game

- Use this mode when tracking a single cash game table.
- Start a new session and choose Action Tracker.
- Set the number of seats based on active players at the table.
- Enter player names, seat assignments, and buy-ins.
- Press Start Hand when ready.

## Tournament

- Use this mode when tracking a single-table tournament.
- Start a new session and choose Action Tracker.
- Set the total seats, including players who may arrive late.
- Add players to the seat map and assign starting stacks.
- Press Start Hand when ready.

## Tournament Director

- Use this mode for tournament setup and management.
- Enter the player count, buy-in, and late-registration settings.
- Choose your chip denominations and confirm the starting blind level.
- Add player names to the roster.
- Review the payout structure and begin the tournament.
