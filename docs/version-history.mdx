### 1.8.0 — 2026-11-17 GO Mode and Degen Variants

- **Added a new GO Mode for pass-and-play poker**
  - Supports NLH and PLO on a single device.
  - Players pass the phone during their turns and privately reveal their cards.
  - Includes opponent-stack rounding, bet shortcuts, fold/check/call controls, and pot tracking.
- **Added 8 degenerate poker variants**
  - **Second Best:** the second-best hand wins.
  - **3-2-1:** a three-card flop, two-card turn, and one-card river.
  - **Ocean:** adds an extra street after the river.
  - **Showtime:** folded cards become visible.
  - **Mandatory 3-Bet:** players cannot limp or call before a 3-bet occurs.
  - **Red River:** a red river card triggers another river card.
  - **Win the Button:** each hand winner receives the button.
  - **Deuces Wild:** all deuces act as wild cards.
- **Improved card entry**
  - Added visual rank-and-suit keypads instead of requiring typed card notation.
  - Prevented the same card from being selected twice.
  - Improved support for hole cards and boards containing more than five cards.
- **Improved all-in and showdown handling**
  - Added clearer win percentages, chop outcomes, dirty outs, and winning-card highlights.
  - Added a separate all-in view showing players, hole cards, pots, boards, and payouts.
  - Improved automatic winner determination and pot awards.
- **Added Firebase account support**
  - Replaced the temporary login system with Firebase authentication.
  - Supports Google sign-in, email/password login, account creation, password resets, and sign-out.
  - Uses Firebase storage for completed sessions and hand histories.
- **Added completed-session and hand-history tracking**
  - Sessions can now be marked as completed and reviewed later.
  - Hand histories show actions, hole cards, board cards, winnings, and net results by street.
  - Added CSV export and Google Sheets export.
- **Expanded tournament setup**
  - Added blind-schedule generation based on starting stack and desired duration.
  - Added break timing, Turbo/Balanced structures, and color-up breaks.
  - Added payout generation based on ITM places or a percentage of the field.
  - Added payout steepness controls and bracketed payout ranges.
  - Added saved tournament presets that can be stored, loaded, imported, and exported.
- **Added more display settings**
  - Chips or big blinds can be used for stack and bet displays.
  - Cards can use traditional red/black suits or a four-color system.
  - Player positions and betting amounts can be hidden or shown.
  - The interface can display every action or only the latest action.
- **Improved the main session experience**
  - Added separate tabs for in-progress sessions, completed sessions, and saved hand histories.
  - Added session names and clearer sign-out controls.
  - Added a new mode-selection screen for Action Tracker, GO Mode, Tournament Director, and Degen Variants.

### 1.7.0 — 2026-11-05 Tracker features and tournament improvements

- Added **Compact Mode**, with a mobile-friendly hand view, card-entry controls, and keyboard shortcuts for poker actions and undo.
- Added **temporary game scheduling** for cash games, including recurring or hand-specific variants, bomb pots, overlap checks, and a way to revert to the base game.
- Added a **Big Blinds display option** for stacks and betting amounts.
- Added **Google Sheets hand-history export**, including formatted player, card, action, and winner information.
- Added support for **multiple active tournaments**, with controls to switch between, pause, resume, create, and delete tournaments.
- Improved tournament setup and management: roster entry can be deferred until the money, rebuy rules are configurable, payout displays reflect chops, and bust recording supports searching and selecting players.
- Added **color-up breaks** to blind schedules, with chip-race handling.
- Refined all-in runouts and views for multiple boards, including board-by-board dealing and more detailed winner/equity displays.
- Updated typography and number formatting
