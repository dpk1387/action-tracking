title: "Cash Game Setup"
---

Use this page to configure a cash game before starting play. Set the game format, seating, stacks, blinds and stacks, then start tracking the event.

## Variants

Choose the game variant:

- NLH
- PLO4, PLO5, PLO6, PLO8
- Pineapple (Pineapple, Crazy Pineapple, Lazy Pineapple are available)
- Short Deck (6+)
- Super Hold 'Em

## Seating

The app supports up to 12 seats for a cash game. Set the number of seats to match the number of players at the table, not including players who may join late.

To assign seats, enter the seating order in the correct order clockwise. It does not matter who is Player 1, although we recommend that be the seat left of the dealer.

## Button

Select who gets the button on the first hand. By default this is random.

## Stacks

Set each player’s starting stack below their name.

Set all stacks:

- Use this to assign the same stack size to every player.
- This is most useful in tournaments, where all players often begin with the same stack.

Enter stack sizes in big blinds:

- Toggle this option on if you want to enter stack sizes in big blind units instead of raw chip value.

Default stacks:

- If no stack is entered for a player, the app will automatically assign 100 big blinds.

## Ante

Antes are mandatory contributions added to the pot before the hand begins. Blinds are still required even when an ante is enabled.

Choose one of the following:

1. No ante - Default for cash games.
2. Traditional ante
   - Every player contributes an ante.
   - This is usually around 10–20% of the big blind.
3. Big Blind Ante (BBA)
   - The big blind contributes the ante for the whole table.
   - This is set to 1 big blind.
   - Two modifiers are available for the Big Blind to pay a 0.5 BB ante:

     - Short-hand reduction: If the table has N players or less (default 5)
     - Level reduction: Big Blind pays a half-ante for the first N levels (default 2)
4. Button Ante (BA)

   - The button contributes the ante for the whole table.
   - This is set to 1 big blind.
6. 3 blinds

   - The small blind, big blind, and UTG player post blinds
   - The third blind is by default equal to 2 big blinds. However, in 1/2 and similar blinds the third blind is equal to 2.5 big blinds (so \$5 in a 1/2 game).
7. 4 blinds

   - Blinds are posted by the small blind, big blind, UTG, and UTG+1 players
   - Third blind is equal to 2 or 2.5 big blinds
   - Fourth blind is equal to 2x the third blind

## Blinds

Set the table blind structure by entering:

- Small blind
- Big blind
- Ante, if applicable

This gives you the correct blind schedule for the game you are tracking.

## Straddle

Allow straddle (UTG):

- The player to the left of the big blind may straddle. 
- If there are 3 blinds, the straddle option is given to UTG+1
- If there are 4 blinds, the straddle option is given to UTG+2
- This is enabled by default.

Allow re-straddle:

- Allows additional players after the initial (either UTG, +1, +2) straddler to re-straddle.
- This is disabled by default.
- It is unavailable when UTG straddle is turned off.

## Quick Example

A common cash game setup might look like this:

- Game type: Cash
- Betting limit: No-Limit
- Variant: Texas Hold ’Em
- Seats: 6
- Ante: No ante
- Blinds: 1 / 2
- Action clock: 60 seconds
- Straddle: Off
